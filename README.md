# Agua de verano

Visual generativa creada con Hydra.

## Cómo usarla

1. Abrí el [editor de Hydra](https://hydra.ojack.xyz/).
2. Copiá el contenido de [`agua-de-verano.js`](agua-de-verano.js) y pegalo en el editor.
3. Ejecutá todo el código con `Ctrl + Shift + Enter`.

El archivo conserva el código original de la visual y envía la salida a `o0`.
